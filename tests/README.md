# ADBweb Tests

## Overview
This folder contains pytest-based integration tests for the ADBweb backend APIs and core workflows. Allure and HTML reports are generated by default via `pytest.ini`.

## Test Files
- `test_all.py`: All coverage in a single file (dashboard, devices, scripts, templates, AI scripts, AI element locator, device health, uploads, performance, boundary cases, security checks).

## Requirements
- Python 3.8+
- Backend running (default `http://localhost:8000`)
- Optional: frontend running (default `http://localhost:5173`)

## Environment Variables
- `API_BASE_URL` (default: `http://localhost:8000/api/v1`)
- `FRONTEND_BASE_URL` (default: `http://localhost:5173`)
- `TEST_DB_PATH` (default: `../backend/test_platform.db`)
- `TEST_API_KEY` (must match backend `API_ACCESS_KEY` when auth is enabled)
- `API_ACCESS_KEY` (fallback if `TEST_API_KEY` not set)

## Install Dependencies
```bash
pip install -r requirements.txt
```
Includes `websocket-client` for interactive WebSocket tests.

## Run Tests
```bash
python -m pytest -v
```

Pytest will generate:
- Allure results in `allure-results/`
- HTML report in `reports/report.html`

## Allure Report
```bash
allure generate allure-results -o allure-report --clean
allure serve allure-results
```

## Notes
- If the backend is not running, API tests will be skipped.
- If the test database is missing, DB tests will be skipped.
