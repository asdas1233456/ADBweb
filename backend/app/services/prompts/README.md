# AI脚本生成器提示词文件

本目录包含AI脚本生成器使用的所有提示词文件。将提示词分离到独立文件中，便于维护和修改。

## 文件说明

### 1. python_script_generation.txt
用于生成Python自动化脚本（基于uiautomator2）的提示词。

**用途**: 当用户选择生成Python脚本时使用

**修改建议**:
- 调整API速查表，添加或删除常用API
- 修改示例代码，适配你的项目需求
- 调整输出格式的JSON结构

### 2. adb_script_generation.txt
用于生成ADB Shell脚本的提示词。

**用途**: 当用户选择生成ADB脚本时使用

**修改建议**:
- 调整坐标参考值（如果你的设备分辨率不同）
- 修改命令速查表，添加常用的ADB命令
- 调整示例脚本，适配你的测试场景

### 3. prompt_optimization.txt
用于优化用户输入的提示词。

**用途**: 当用户点击"优化提示词"按钮时使用

**修改建议**:
- 调整优化要点，根据你的团队规范
- 修改示例，展示你期望的提示词格式
- 添加或删除检查项

## 如何修改提示词

1. **直接编辑文件**: 使用任何文本编辑器打开对应的.txt文件
2. **重启服务**: 修改后需要重启后端服务才能生效
3. **测试验证**: 修改后建议测试生成效果，确保符合预期

## 提示词编写技巧

### 1. 结构清晰
```
# 角色定义
你是...

# 核心规则
1. 规则1
2. 规则2

# API/命令速查
...

# 示例
...

# 输出格式
...
```

### 2. 使用Few-shot示例
提供1-2个高质量示例，帮助AI理解期望的输出格式。

### 3. 明确输出格式
使用JSON格式约束输出，便于程序解析。

### 4. 控制Token消耗
- 精简描述，避免冗长解释
- 合并重复内容
- 只保留核心API文档

## Token消耗参考

| 文件 | 大约Token数 | 说明 |
|------|------------|------|
| python_script_generation.txt | ~900 | 已优化 |
| adb_script_generation.txt | ~900 | 已优化 |
| prompt_optimization.txt | ~80 | 已优化 |

## 注意事项

1. **编码格式**: 文件必须使用UTF-8编码
2. **换行符**: 建议使用LF（\n）而不是CRLF（\r\n）
3. **特殊字符**: 避免使用可能导致解析错误的特殊字符
4. **文件大小**: 建议单个文件不超过2000 tokens（约8000字符）
